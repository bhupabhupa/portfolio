# Bhupendra Tandel — Portfolio

Personal portfolio site: Engineering Manager, Delivery Lead and Full-Stack Engineer.

Built with Next.js (App Router), React, TypeScript and Tailwind CSS. Fully static, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All text (profile, experience, projects, GitHub repos, skills) lives in [`src/data/profile.ts`](src/data/profile.ts). The layout reads from it, so most updates only need changes there.

## Scripts

- `npm run dev`: start the dev server
- `npm run build`: production build
- `npm run lint`: lint
